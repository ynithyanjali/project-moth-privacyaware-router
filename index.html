Methodology and limitations

The router applies basic sensitive-pattern checks and a word-count threshold. It is a learning prototype, not a verified privacy or complexity classifier.

Measured: routing decision time for recorded prompts and local Gemma response time for successful local calls. Local inference times include model loading and other overhead.

Not measured: cloud inference latency, cloud costs, response correctness, model quality, or production reliability. A simulated-cloud selection never sends the prompt to a cloud service.

Results reflect one local run on a small synthetic prompt set. No private prompt text is included in this dashboard.
